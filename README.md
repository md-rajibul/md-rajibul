
# E-commerce App

A frontend e-commerce web application built with React and Vite.

## Technologies Used
- React.js
- JavaScript
- Vite
- Tailwind CSS
- DaisyUI

## Dependencies
- react-router-dom
- react-hot-toast
- react-rating

## Project Overview
This project explores modern React application
development and e-commerce user interfaces.

## Installation

1. Clone the repository:
   git clone https://github.com/md-rajibul/ecommerce-app.git

2. Open the project directory:
   cd ecommerce-app

3. Install dependencies:
   npm install

4. Start the development server:
   npm run dev
